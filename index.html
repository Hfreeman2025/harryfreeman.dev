    How this page works

    One building, drawn two ways from the same content. On a large screen that welcomes motion, it is a lit 3D studio in three.js, seen from the door: the filing cabinet’s drawers slide out, a folder you pull turns the camera to the desk where that tool was built, and its screen plays the tool. On a phone, with reduced motion, without WebGL or without script, it is a flat office: the same directory, cabinet, folders and Reception as HTML. Every object in the room is a real button or link, so the keyboard reaches all of it; Esc steps back.

    The loops were recorded from the real tools in a silent headless browser and are labelled recorded; Open launches the tool live. The studio’s light follows Great Britain’s grid: one request to the NESO Carbon Intensity API for the current half-hour, shown on the sign with its time and source. When it fails, the sign says so and the light stays neutral. The radio plays Listen to the Grid, from its own embeddable build, and only once you press it.

    Reception runs ask-the-record entirely in your browser. Keyword search and the suggested questions need no download; your own question loads the meaning model on first use, about 50 MB, served from this site and cached. Your question never leaves the page. Third-party code and data are listed in NOTICES.txt.
