The ten pieces

The brief

Three documents set the bar for every desk. Each piece was built against all three, in order; the reviewer checked work against them and sent it back when it fell short.

BRIEF.md The rules

  • A clean room: personal work, no employer code, names or data, and no private data of any kind.
  • Local only. No accounts, logins, commits or publishing.
  • Honest data: label times and sources, show an explicit offline state, never present stale or sample data as live.
  • It must not look AI-generated. Deliberate type and colour, keyboard use, reduced motion, good contrast, phones.
  • Right-sized engineering: strict types, runtime validation of every response, real tests for the tricky core, licence-checked dependencies.

V2.md Better, more polished, more innovative

  • An identity derived from a medium, written down in six lines, with no shared template.
  • Engine first: the working thing on the first screen, on a laptop and a phone.
  • One signature idea per piece, built properly.
  • Every state designed, zero console errors, tested in Chromium, WebKit and Firefox, performance measured.
  • Two hostile self-critique passes before reporting.

V3.md Visionary, not just good

  • A real technical core, implemented properly and cited, explained in plain words.
  • A wow inside ten seconds, with any recorded run labelled as recorded.
  • Honest by construction: inferred things labelled inferred, real accuracy reported even when it is unflattering.
  • Downloads stated, cached, cancellable and survivable; fallbacks designed, never a crash.
  • Machine rules: silent browser automation, shared model weights, one test browser at a time.

How this page works

The studio is a 1:50 model built in Three.js from a plan of boxes. The lamp’s light and shadows on the floor were baked ahead of time by ray tracing that same plan; only the figures and screens are lit live. The figures replay the build timeline: who built what, each hand-off to the reviewer, each piece sent back. Each screen plays a silent loop recorded from the real piece in a headless browser.

Ask the studio runs ask-the-record entirely in your browser. Keyword search and the three suggested questions need no download; your own question loads the meaning model on first use, about 50 MB (a 23 MB embedding model and 27 MB of WebAssembly runtime), served from this site and cached by your browser. Your question never leaves the page.

Phones, reduced motion and screen readers get this page as a list with a still photograph of the model. See the list version.
