## Selected work

### Carbon-footprinting platform, the firm's first productised service, live with an enterprise client

The platform turns a client's raw invoices, meter data and certificates into an auditor-ready greenhouse-gas footprint, covering Scope 1 to 3, SECR, SBTi targets and supplier engagement. All clients share one stack: Postgres row-level security keeps each client's data separate, every figure is traceable to its source, and PII is removed before any model sees it. Built with TypeScript, Fastify, PostgreSQL, React, Python, GPT-4o, Document Intelligence, Entra ID and Azure Container Apps.

### Document AI service, a live shared capability, built once and reused everywhere

One shared extraction service instead of a separate parser for each product. The service reads utility invoices, activity workbooks and F-gas records, was tuned on 21 real client workbooks, and has 369 regression tests. Built with Python, Azure Functions, Document Intelligence and API Management.

### Environmental site assessment, a pilot with a UK construction group

The assessment tool automates the desk-based screening stage for construction sites. The tool checks 56 spatial data layers against 14 compound risk rules and drafts an ISO 14001 register, which a qualified specialist signs off. Built with Python, FastAPI, GeoPandas, PostgreSQL, Leaflet and Azure OpenAI.

### Regulation RAG, cited answers for consultants

Regulation RAG answers questions across global regulations with paragraph-level citations and a confidence score for each claim, checked by a fact-checking agent. Regulation RAG was first built for an energy company's AI innovation programme. Built with Python, LangChain, Claude and Qdrant.

### More

Dispatching sprint-planner tasks to coding agents with human review; a meeting-signal pipeline for commercial follow-ups; climate-hazard screening over CMIP6 projections; a proposal builder; and CSRD double-materiality and LCA tools.
